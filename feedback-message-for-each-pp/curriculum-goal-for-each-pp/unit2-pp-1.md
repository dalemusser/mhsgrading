# Curriculum goal
At this progress point, players navigate the alien ruins and match topographic maps with corresponding elevation profiles. Through this puzzle, players learn how topographic maps represent the shape and elevation of land.

More specifically, players learn to use cardinal directions—north, south, east, and west—to orient themselves on a map, distinguish between land and water features, and interpret contour lines. Contour lines connect locations with the same elevation, while their patterns and spacing indicate the height, shape, and steepness of the terrain.

The puzzle asks players to connect two different representations of the same landscape: a top-down view shown on a topographic map and a side-view cross-section shown in an elevation profile. By observing the contour-line patterns and changes in elevation, players identify which elevation profile corresponds to each topographic map.
