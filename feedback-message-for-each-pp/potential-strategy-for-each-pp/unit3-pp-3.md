# Information and Strategies Available to Players

1. Players can review the pollution-source location identified and marked by DANI during the previous investigation. This provides an important starting point for determining the claim they should make about where the pollution entered the river.

2. Players can use the sensor evidence collected during the previous progress point, especially the pattern in which an upstream location shows a **green** result while a downstream location on the same flow path shows a **red** result. This pattern helps identify the section of the river where the pollution source is likely located.

3. Tara and DANI provide dialogue that reviews important concepts of scientific argumentation, including the roles of **claim, evidence, and reasoning**. Players can use this guidance to recall how the three components should work together in a complete scientific argument.

4. The argumentation system provides two pieces of background or reference information that players can consult while constructing their argument. These resources can help them connect their observations from the pollution investigation with the scientific logic needed to support the claim.

5. Players can inspect the detailed information contained in each available claim, evidence, and reasoning node before making a selection. Comparing the available options can help them determine which combination forms a logically coherent argument.

6. Players should evaluate whether the selected evidence directly supports the proposed pollution-source location. In particular, they can use the upstream-green and downstream-red sensor pattern to determine where the pollutant must have entered the river.

7. Because players must select all three argument components in this activity, they can check whether the selected reasoning clearly explains **why the evidence supports the claim**, rather than simply choosing statements that are individually related to pollution.

8. After the player submits an argument, Dr. Toppo provides feedback indicating whether the argument is correct. If the submission is incorrect, the feedback identifies problems with the selected components or their logical relationship and provides guidance that can help the player revise the argument.

9. Players can use Dr. Toppo’s feedback, the available reference information, the sensor results, and DANI’s marked pollution-source location to reconsider their selections and revise the argument until the claim, evidence, and reasoning form a scientifically coherent explanation.
