# Information and Strategies Available to Players
1. Players can apply the scientific-argumentation and watershed knowledge developed in previous progress points. Before beginning the argumentation task, they can select optional dialogue choices that allow Dr. Toppo to review the definitions and functions of claims, evidence, and reasoning. These dialogue options can be selected repeatedly when additional review is needed.

2. During the task, players can read the information contained in each available argumentation node and determine whether it should be included in the argument. They can compare the nodes with the investigation question and the observations collected from the Western and Eastern Falls.

3. The reasoning component is provided as a fixed node. Therefore, players’ main responsibilities are to select the claim that correctly identifies the larger watershed and choose the evidence that appropriately supports that claim.

4. Players can use two reference tools within the argumentation interface. One tool explains the scientific relationship between watershed size and water flow rate. The other presents a comparison table containing the observations collected from the two waterfalls, including flow rate, waterfall height, salinity, and distance from the ocean.

5. Players can use the comparison table to identify which waterfall has the greater flow rate and distinguish relevant evidence from observations that do not directly indicate watershed size. They can then select the claim and evidence that are consistent with the provided reasoning.

6. After submitting the completed argument, players receive feedback from Dr. Toppo indicating whether the argument is correct. When the argument is incorrect, the feedback identifies the specific problem, such as an unsupported claim or irrelevant evidence, and provides a hint that can help the player revise the argument.

7. Players can use Dr. Toppo’s feedback and the available reference tools to reconsider their selections, revise the argument, and resubmit it until the claim, evidence, and provided reasoning form a scientifically coherent argument.
