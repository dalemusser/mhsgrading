# Solar Still Design

The score measures whether the player selects the three design settings that let the solar still (solar desalinator) collect the maximum amount of water. Each correct selection earns half a point.

* **0.5 point:** Roof shape — the player selects **Tilted Out** (the icon on the left).
* **0.5 point:** Extra roof — the player selects the **X mark**, i.e. no extra converting layer is added.
* **0.5 point:** Glass roof temperature — the player selects **cold**.
* **0 points** for each setting left at any other option, or if the design is not submitted.

```text
Final Score = 0.5 × Number of correct selections
```

The maximum score for this progress point is **1.5 points**.
