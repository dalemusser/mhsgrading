# Place the Supply Crates in the Correct River

The score measures how many of Tera’s three supply crates the player sends down the correct river so that they float back to her camp. Each crate is placed once.

* **1 point:** The crate is placed in the correct river and reaches Tera’s camp.
* **0 points:** The crate is placed in the wrong river (the crate is lost), or the crate is not placed.

```text
Final Score = Number of correct crate placements
```

The player places 3 crates, so the maximum score for this progress point is **3 points**.
