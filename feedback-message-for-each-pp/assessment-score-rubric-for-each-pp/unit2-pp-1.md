# Topographic Map Matching
The score is determined by the number of attempts the player requires to submit the correct set of matches.
1. 2 points: The player submits the correct solution within 1 or 2 attempts.
2. 1 point: The player submits the correct solution within 3 or 4 attempts.
3. 0 points: The player requires 5 or more attempts, does not submit a correct solution, or does not attempt the task.
The maximum score for this progress point is 2 points.
