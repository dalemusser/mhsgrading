# Watershed Size and Flow-Rate Matching Activity
The score is determined by the number of attempts the player requires to submit the correct set of matches.

* **2 points:** The player submits the correct solution within 1 to 3 attempts.
* **1 point:** The player submits the correct solution on the 4th or 5th attempt.
* **0 points:** The player requires more than 5 attempts, does not submit a correct solution, or does not attempt the activity.

The maximum score for this progress point is **2 points**.
